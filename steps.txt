# GCP Deployment Guide: 2-VM Architecture

This guide explains how to set up two Virtual Machines (VMs) on Google Cloud Platform (GCP) to run your To-Do application.
*   **VM 1 (Application Server)**: Runs Node.js and serves the website.
*   **VM 2 (Database Server)**: Runs MySQL database.

---

## Phase 1: GCP Infrastructure Setup

### Step 1: Create the Database VM (VM 2)
1. Go to the **GCP Console** -> **Compute Engine** -> **VM instances**.
2. Click **Create Instance**.
3. Configure the VM:
   *   **Name**: `db-server` (or `vm2`)
   *   **Region/Zone**: Choose the same region and zone as your app VM (e.g., `us-central1-a`).
   *   **Machine configuration**: `e2-micro` (cost-effective and sufficient).
   *   **Boot disk**: Ubuntu 22.04 LTS (Standard persistent disk, 10 GB).
4. Click **Create**.
5. **Note the Internal IP** of this VM (e.g., `10.128.0.3`). You will need it later.

### Step 2: Create the Application VM (VM 1)
1. In VM instances, click **Create Instance**.
2. Configure the VM:
   *   **Name**: `app-server` (or `vm1`)
   *   **Region/Zone**: Same as `db-server` (e.g., `us-central1-a`).
   *   **Machine configuration**: `e2-micro`.
   *   **Boot disk**: Ubuntu 22.04 LTS.
   *   **Firewall**: Check **Allow HTTP traffic** (if you plan to use standard web ports) or we will create a firewall rule for port `3000` next.
3. Click **Create**.
4. **Note the Public IP** (External IP) of this VM. This is how you will access your website.

### Step 3: Configure GCP Firewall (Allow Access to Port 3000)
By default, GCP blocks external access to port `3000`. You must open it:
1. Search for **VPC network** in the top search bar and click **Firewall**.
2. Click **Create Firewall Rule**.
3. Configure the rule:
   *   **Name**: `allow-node-port-3000`
   *   **Targets**: `All instances in the network`
   *   **Source IPv4 ranges**: `0.0.0.0/0` (Allows anyone to access the site)
   *   **Protocols and ports**: Check **Specified protocols and ports**, select **TCP**, and type `3000`.
4. Click **Create**.

## Phase 2: Database VM Configuration (VM 2)

SSH into **VM 2 (db-server)** via the GCP Console by clicking the **SSH** button next to it. Run the following commands:

### Step 1: Install MySQL
```bash
sudo apt update
sudo apt install -y mysql-server
```

### Step 2: Configure MySQL to Allow Remote Connections
By default, MySQL only listens to local requests (`127.0.0.1`). We need to configure it to listen to VM 1's IP.
1. Open the MySQL configuration file:
   ```bash
   sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf
   ```
2. Find the line:
   ```text
   bind-address            = 127.0.0.1
   ```
3. Change it to:
   ```text
   bind-address            = 0.0.0.0
   ```
   *(Note: `0.0.0.0` allows MySQL to accept connections on all network interfaces. GCP's internal network firewalls will keep it secure.)*
4. Save and exit (Press `Ctrl+O`, then `Enter`, then `Ctrl+X`).
5. Restart MySQL:
   ```bash
   sudo systemctl restart mysql
   ```

### Step 3: Create MySQL User and Database
1. Access the MySQL shell as root:
   ```bash
   sudo mysql
   ```
2. Create the database (though the app does it, it's good to ensure it exists):
   ```sql
   CREATE DATABASE IF NOT EXISTS todo_db;
   ```
3. Create a user that VM 1 can connect with. Replace `VM1_INTERNAL_IP` with the actual **Internal IP of VM 1** (e.g. `10.128.0.2`):
   ```sql
   CREATE USER 'root'@'VM1_INTERNAL_IP' IDENTIFIED BY 'root';
   ```
4. Grant all privileges on the database to this user:
   ```sql
   GRANT ALL PRIVILEGES ON *.* TO 'root'@'VM1_INTERNAL_IP' WITH GRANT OPTION;
   FLUSH PRIVILEGES;
   ```
5. Exit MySQL:
   ```sql
   EXIT;
   ```

## Phase 3: Application VM Configuration (VM 1)

SSH into **VM 1 (app-server)** via the GCP Console and run these commands:

### Step 1: Install Node.js & Git
```bash
sudo apt update
sudo apt install -y nodejs npm git
```

### Step 2: Copy the Code to VM 1
You can push your local folder to a private GitHub repository and clone it on VM 1, or recreate the files directly on VM 1:
1. Create the project directory:
   ```bash
   mkdir todo-app
   cd todo-app
   ```
2. Initialize and install dependencies:
   ```bash
   npm init -y
   npm install express mysql2
   ```
3. Create the directories:
   ```bash
   mkdir public
   ```

### Step 3: Write server.js (Pointing to VM 2)
Create `server.js` using `nano`:
```bash
nano server.js
```
Paste the server code. **IMPORTANT**: Update the `dbConfig` to point to VM 2's internal IP:
```javascript
const dbConfig = {
    host: 'VM2_INTERNAL_IP', // <--- Change this to the Internal IP of your db-server VM
    user: 'root',
    password: 'root',
};
```
Save and exit.

### Step 4: Write Frontend files
Create the HTML, CSS, and JS files inside the `public/` directory:
```bash
nano public/index.html
nano public/style.css
nano public/script.js
```
*(Copy and paste the code from your local files into each).*

---

## Phase 4: Run and Test

On **VM 1 (app-server)**, start your application:
```bash
node server.js
```

You should see:
```text
Server listening on port 3000
Database 'todo_db' ensured.
Table 'tasks' ensured.
```

### Accessing your App
Open a web browser on your computer and navigate to:
`http://<VM1_EXTERNAL_IP>:3000`

*(Replace `<VM1_EXTERNAL_IP>` with the public External IP of VM 1 from the Compute Engine console).*

---

## Phase 5: Keep the App Running (Optional but Recommended)
To prevent the application from closing when you close the SSH terminal, install `pm2`:
```bash
sudo npm install -g pm2
pm2 start server.js --name "todo-app"
```
This will keep the app running in the background. To check status: `pm2 status`.
